קישור לפרויקט Autodesk

בחר HUB (BIM 360 / ACC) ואת הפרויקט המתאים

חיבור BIMBOT ל-Autodesk (פעם אחת, מנהל מערכת)

  1. ב-aps.autodesk.com → My Apps פתח את האפליקציה (או Create application עם Data Management API) והעתק Client ID ו-Client Secret.
  2. ב-ACC: Account Admin → Custom Integrations → הוסף את אותו Client ID (בכל HUB שצריך).
  3. הדבק כאן ולחץ "בדיקה ושמירה". הפרטים נבדקים מול Autodesk ונשמרים רק אם הם תקינים.
